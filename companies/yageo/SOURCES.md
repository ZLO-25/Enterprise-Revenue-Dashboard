# 國巨 Yageo（2327）資料來源與更新步驟

- 資料檔：`data/yageo.json`（schema `v1`）　頁面：`/yageo/`　模板：`templates/generic.frag.html`（通用模板）
- 單位：**百萬元新台幣**（`rev`、`gp`、`opInc`、`ni`、`ocf`、`capex`、`fcf`、`cash`、`debt`、`equity`、`pretax`、`tax`、`buyback`、`sbc`）。財報原始單位是**新台幣仟元**，除以 1,000 後保留小數 3 位；`eps` 為元，**已換成今天的股數基準**（見「EPS 與股數換算」）；`shOut` 為百萬股（今天的基準）。
- 會計準則：**IFRS 合併報表**（台灣 2013 年起採用；更早是我國舊會計準則，本頁不收）。
- 掛牌：臺灣證券交易所（TWSE，上市）。股價核對用證交所 STOCK_DAY（`price.twse: "2327"`），並用 `price.adj` 把 Yahoo 已往回調整的股本事件換回原始價再比（`tools/prices_update.py` 的 `adj_factor`，2026-11-20 新增）。
- 頻率：每季。營運成果新聞稿＋董事會通過合併財務報告：第一季約 4 月中下旬、第二季約 7 月底、第三季約 10 月底、全年約隔年 2 月底；每月上旬公告上個月自結合併營收。
- 排程：週二至週六每日檢查（見 docs/SCHEDULE_PROMPT.md；公布日隔天先做「快報」，再「補完」「核對」）。只補「上次資料之後」的新期間，舊數字不重抓。

## 期間

1Q13（2013/1–3）–最新一季，共 55 季（到 3Q26）。從 1Q13 開始是因為這是台灣採用 IFRS 的第一季，也是公開資訊觀測站 IFRS 合併財報（t164sb01）最早的一季。

跟萬潤（`companies/allring/SOURCES.md`）一樣，用 repo 的孤兒分支 `tw-raw`：

```
你（容器）                         GitHub Actions（tw-raw 分支）
  │ 1. 改 want.txt，push 到 tw-raw ──► 2. tw-raw.yml 自動觸發
  │                                     3. tools/tw_raw.py 逐行抓網址，存 raw/2327/…

 6. 用 tw-raw 分支 tools/yageo/ 的程式產生新一季
```

1. **公開資訊觀測站 IFRS 合併財務報告**（t164sb01，會計師核閱／查核）：資產負債表、綜合損益表、現金流量表。

### 第四季推算
- 營收、毛利、營業利益、淨利、稅前淨利、所得稅：**4Q ＝ 全年（年度合併財務報告）－ 前三季單季**；現金流＝全年累計－前三季累計。
- **第四季 EPS ＝ 公司「第四季（暨全年度）營運成果」重大訊息公布的單季 EPS**（2013–2025 年都有）。不用「全年 − 前三季累計」，因為年中現金減資讓股數大幅變動，兩者在 2014 年差 0.41 元、2017 年差 1.05 元。

## EPS 與股數換算（重要）

國巨 2013–2025 年的股本事件（全部來自重大訊息全文）：

| 日期 | 事件 | 比例（新股數 ÷ 舊股數） | 公司 EPS 是否追溯 |
|---|---|---|---|
| 2013-08-09 登記，09-18 新股上市 | 現金減資約 30% | 1,543,715,867 ÷ 2,205,308,382 | 否 |
| 2014-09-05 登記，10-09 新股上市 | 現金減資約 70% | 0.30256942478 | 否 |
| 2016-06-28 核准，07-12 登記 | 現金減資約 20% | 0.80045445859 | 否 |
| 2017-07-06 登記，08-18 新股上市 | 現金減資約 30% | 0.69878452861 | 否 |
| 2018-07-09 除權 | 股票股利每股 1.98116669 元 | 1.198116669 | 是 |
| 2022-09-15 登記，約 10-20 新股上市 | 現金減資約 20% | 0.79592497057 | 否 |
| 2024-08-15 除權 | 股票股利每仟股 194.836497 股 | 1.194836497 | 是 |
| 2025-08-25 新股上市 | 面額 10 元改 2.5 元，1 股換 4 股 | 4 | 是 |

Yahoo 的收盤價把以上 8 個事件都當成「分割」往回調整（yfinance `splits`：2013-09-05 0.7、2014-09-29 0.302569、2016-08-03 0.800454、2017-08-07 0.6987845、2018-07-09 1.198117、2022-10-20 0.795925、2024-08-15 1.1948365、2025-08-14 4），所以本益比要用同一個基準的 EPS：

- 股票股利、面額變更：財報公布日 `rd` **之後**才發生的才除（之前發生的，公司在報表裡已經追溯調整過）。
- 現金減資：公司不追溯，所以 EPS 生效日之前結束的季度一律除。EPS 生效日＝公司加權股數開始改用新股數的日子：2013、2016、2017 用變更登記日；2014、2022 用新股上市日（3Q14、3Q22 的公司 EPS 仍以減資前股數為主）。
- **混合季**：3Q13、3Q14、4Q22 的公司 EPS 是減資前後股數混合計算的，無法精確換算（需要附註的加權平均股數），頁面 `notes.unavailable` 寫成待確認，並寫出與「淨利 ÷ 期末股數」的差距。
- `shOut`＝普通股股本 ÷ 當時面額 − 庫藏股股數（3999），再乘上期末之後所有事件的比例（用股本生效日判斷）。
- 程式：tw-raw 分支 `tools/yageo/build_yageo.py` 的 `EVENTS`、`factor()`、`shfactor()`。**以後若有新的配股或分割，要加進 `EVENTS` 並重算全部 EPS 與 shOut**（同時在 companies.json `price.adj` 加 Yahoo 的事件日與比例）。

### 重編（本頁保留第一次公布的數字）
- 2017 年出售飛磁（Ferroxcube）：2016 年各季在 2017 年報表重編為繼續營業單位（2016 全年營收 296.2 → 277.8 億元）。
- 2020 年第三、四季：收購基美的價格分攤調整，3Q20 歸屬母公司淨利 36.3 → 26.7 億元。
- 2021 年各季：併入奇力新後在 2022 年報表重編（1Q21 營收 237.5 → 280.3 億元）。
- 2017 與 2022 年的年增率因此是新口徑比舊口徑。

## 核對規則

1. `python3 tools/validate.py yageo`：毛利率、營業利益率與金額自洽；`fcf = ocf − capex`；四季加總＝全年；`waterfall` 小計；日期格式。
2. `build_yageo.py` 會印出第四季新聞稿 EPS 和「全年 − 前三季累計」差超過 0.015 元的年份（減資年份本來就會差）；沒有新聞稿時改用相減法並印出。
3. 抽查：換算後 EPS 和「淨利 ÷ shOut」除了 3 個混合季，差距都在 5% 以內（2Q20 期末大量發行新股，差 4%）。

## 更新步驟（每日排程「快報」）

1. 查有沒有新財報：`events` 的公布日到了，或 tw-raw 分支重抓當年重大訊息主旨（先刪 `raw/2327/mops/t05st01_<民國年>.html`），看有沒有「營運成果」或「合併財務報告業經提報董事會通過」。**沒有 → 跳到第 6 步。**
2. tw-raw 分支 `want.txt` 加 `fs 2327 <年> <季> <年> <季>`；第四季另外加那一則「第四季度營運成果」的全文（`python3 tools/yageo/detail_want.py` 會列出），push，等 Actions 跑完再 `git pull`。
3. 在 tw-raw 分支：`mkdir -p work_y && python3 tools/yageo/parse.py raw/2327/fs work_y/fs.json && python3 tools/yageo/ann.py && python3 tools/yageo/rd.py && python3 tools/yageo/build_yageo.py`，把新一季（第四季連同 `annual`）加到 `data/yageo.json`；舊季度不動（`write_data.py` 是第一次建檔用的，排程不要整檔覆寫）。
4. 更新 `waterfall`（新一季，含「非控制權益」一列）、`events`（下一次財報與月營收；公司公告前加 `est:1`）。`guidance` 保持空（公司不給數字財測）。
5. `python3 tools/validate.py yageo`；通過才繼續。
6. 查事件時間軸：併購、公開收購、減資、配股、擴廠（重大訊息）。
7. `asOf` 改成今天（台北時間），`python3 tools/build.py`，commit、push。

## 電話會議（逐字稿）與非 GAAP

- 國巨不自辦法說會，多是受邀參加券商的線上法說會（重大訊息「受邀參加…法說會」），**沒有公開逐字稿**：待確認：逐字稿尚未取得。
- 沒有非 GAAP EPS；新聞稿只會補充一次性項目對 EPS 的影響（例：4Q25 併購整合一次性支出影響約 −0.32 元）。

## 資產負債表欄位（shOut、dilSh、cash、debt、buyback、equity、pretax、tax、sbc）

- 來源：同一份季報的資產負債表與現金流量表，取「本期」欄。
- `cash`＝現金及約當現金（1100）。`equity`＝歸屬於母公司業主之權益合計（31XX）。
- `debt`＝短期借款（2100）＋應付短期票券（2110）＋一年或一營業週期內到期長期負債（2320）＋應付公司債（2530）＋長期借款（2540）；不含租賃負債；沒列的科目視為 0。2013–2015 舊格式的「一年內到期長期負債合計」已含一年內到期公司債，不重複加。
- `buyback`＝現金流量表「庫藏股票買回成本」，年初累計相減；沒有這一列的期間視為 0。
- `pretax`／`tax`＝繼續營業單位稅前淨利／所得稅費用；第四季＝全年－前三季。
- `sbc`：`python3 tools/tw_sbc.py <tw-raw>/raw/2327/fs yageo && python3 tools/bs_merge.py --only sbc yageo`。
