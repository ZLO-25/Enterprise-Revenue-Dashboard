# 萬潤 All Ring Tech（6187）資料來源與更新步驟

- 資料檔：`data/allring.json`（schema `v1`）　頁面：`/allring/`　模板：`templates/generic.frag.html`（通用模板）
- 單位：**百萬元新台幣**（`rev`、`gp`、`opInc`、`ni`、`ocf`、`capex`、`fcf`、`cash`、`equity`、`pretax`、`tax`、`buyback`）。財報原始單位是**新台幣仟元**，除以 1,000 後保留小數 3 位；每股數字（`eps`）為元；股數為百萬股。
- 會計準則：**IFRS 合併報表**（台灣 2013 年起採用；更早是我國舊會計準則，口徑不同，本頁不收）。
- 掛牌：櫃買中心（TPEx，上櫃）。**不是證交所上市**，所以證交所的 STOCK_DAY、BWIBBU 都查不到萬潤；股價改對櫃買中心「個股日成交資訊」交叉核對（`price.tpex: "6187"`，`tools/prices_update.py` 的 `tpex_month`，2026-11-16 新增）。
- 頻率：每季。董事會通過合併財務報告的日期：第一季約 4 月底–5 月中、第二季約 8 月上旬、第三季約 11 月上中旬、全年約隔年 2 月；月營收每月 10 日前公告。
- 排程：週二至週六 08:18（台北）每日檢查（見 docs/SCHEDULE_PROMPT.md；公布日隔天先做「快報」，再「補完」「核對」）。排程只補「上次資料之後」的新期間，舊數字不重抓、不重核；**某個月沒有新財報時，只檢查事件時間軸與公布日**；沒有實質變動就不 commit。

## 期間

1Q13（2013/1–3）–最新一季，共 55 季（到 3Q26）。從 1Q13 開始是因為這是台灣採用 IFRS 的第一季，也是公開資訊觀測站 IFRS 合併財報（t164sb01）最早的一季。

## 怎麼取得原始資料（重要：容器連不到公開資訊觀測站）

容器與使用者電腦的 curl 都連不到 `mopsov.twse.com.tw`；WebFetch 也被 robots 規則擋住。**GitHub Actions 讀得到**，所以用 repo 的孤兒分支 `tw-raw`：

```
你（容器）                         GitHub Actions（tw-raw 分支）
  │ 1. 改 want.txt，push 到 tw-raw ──► 2. tw-raw.yml 自動觸發
  │                                     3. tools/tw_raw.py 逐行抓網址，存 raw/<代號>/…
  │                                        （每 8 筆 commit 一次；觀測站限速，約每分鐘 1–8 份）
  │ 4. git pull tw-raw ◄──────────────── 5. 推回 tw-raw 分支
  ▼
 6. 用 tw-raw 分支 tools/allring/ 的解析程式產生 data/allring.json 的新一季
```

`want.txt` 的格式（一行一個）：
- `fs 6187 <起年> <起季> <迄年> <迄季>`：IFRS 合併財報 `https://mopsov.twse.com.tw/server-java/t164sb01?step=1&CO_ID=6187&SYEAR=<西元年>&SSEASON=<季>&REPORT_ID=C`
- `post 6187/mops/t05st01_<民國年>.html https://mopsov.twse.com.tw/mops/web/ajax_t05st01 encodeURIComponent=1&step=1&firstin=1&off=1&keyword4=&code1=&TYPEK2=&checkbtn=&queryName=co_id&inpuType=co_id&TYPEK=all&co_id=6187&year=<民國年>&month=&b_date=&e_date=`：當年度所有重大訊息
- 已經抓過（檔案 > 3,000 bytes）的不會重抓；要重抓同一季，先刪掉 `raw/6187/fs/<年>Q<季>.html`。

## 來源（依可信度）

1. **公開資訊觀測站 IFRS 合併財務報告**（t164sb01，會計師核閱／查核）：資產負債表、綜合損益表、現金流量表。2019 年起是 inline XBRL（每格有 `ix:nonFraction`），更早是一般表格；解析程式兩種都讀得到。
2. **公開資訊觀測站重大訊息**（t05st01）：「公告本公司董事會通過…合併財務報告／合併財報」的發言日期＝財報公布日 `rd`（`rdB:"p"`）。2020 年 8 月以前的公告主旨還附「每股盈餘為 X 元」（累計 EPS），已逐筆核對與財報一致。
3. 萬潤官網投資人專區 `https://www.allring-tech.com.tw/investor.htm`：合併報告、年報、法說會簡報（PDF）。公司簡介取自 `about1.htm`、`product.htm`。
4. 可信媒體：**只用於事件時間軸**；公司未證實的一律 `unc:1`（例：客戶名稱）。

| --- | --- |
| `rev` | 營業收入合計（4000） |

| `eps` | **基本每股盈餘合計**（9750）。第一到第三季取單季欄（第二、三季報表有「當季」與「累計」兩組欄位，取當季）；第四季見下 |
| `ocf` | 營業活動之淨現金流入（流出）（AAAA）；財報是年初累計，單季＝本期累計－上季累計 |
| `capex` | 取得不動產、廠房及設備（B02700，正數）；同樣用累計相減。**不含**預付設備款、取得無形資產 |
| `fcf` | `ocf − capex` |
| `dps` | 一律 `null`：萬潤一年配一次現金股利 |
| `rd`、`rdB` | 重大訊息「董事會通過合併財務報告」的發言日期；`rdB:"p"` |

### 第四季推算
- **4Q ＝ 全年（年度合併財務報告）－ 前三季單季**（營收、毛利、營業利益、淨利、稅前淨利、所得稅）；現金流＝全年累計－前三季累計。
- **第四季 EPS ＝ 全年基本 EPS － 前三季累計基本 EPS**（第三季報告的「累計」欄）。萬潤沒有單獨公布第四季 EPS（年度財報只有全年、重大訊息只寫全年），這兩個數字都是公司公布的。因為加權平均股數不同，相減值和「第四季淨利 ÷ 股數」可能差幾分錢；頁面 `notes.unavailable` 第一行有寫明。若之後找到公司公布的第四季 EPS（例：法說會簡報），以公司公布值為準。

### 重編
抓到的每一份報告都有「去年同期」比較欄。解析時逐項比對原始值與隔年比較欄：營收、毛利、營業利益、淨利、EPS 在 2013–2025 年**沒有任何重編**；只有營業現金流在 2013 全年與 1Q14～3Q14 有小幅重分類（差 124～341 仟元），採用隔年報告的數字。

## 核對規則

1. `python3 tools/validate.py allring`：毛利率、營業利益率與金額自洽；`fcf = ocf − capex`；四季加總＝全年；`waterfall` 小計；日期格式。
2. 解析程式（`tools/allring/build_allring.py`）另外核對：每一則附 EPS 的重大訊息（2013–2020）累計 EPS ＝ 財報累計 EPS、全年 EPS ＝ 年度財報 EPS；有任何不符會印出 `MISMATCH`，**不符就不發佈**。
3. 資本支出若出現「本季累計比上季累計少」（2Q14 就是），該季 `capex`、`fcf` 填 `null` 並寫待確認，不硬填負數。

**任何一項沒過就不發佈**，回到來源修資料，不要放寬核對。

## 更新步驟（每日排程「快報」步驟；補完、核對見 docs/SCHEDULE_PROMPT.md）

1. 查有沒有新財報：`events` 的公布日到了，或 tw-raw 分支抓當年重大訊息（`post 6187/mops/t05st01_<民國年>.html …`，先刪掉舊檔才會重抓），看有沒有「董事會通過…合併財報」。**沒有新財報 → 跳到第 6 步。**
2. 在 tw-raw 分支 `want.txt` 加 `fs 6187 <年> <季> <年> <季>`，push，等 Actions 跑完（`gh run list -R ZLO-25/Enterprise-Revenue-Dashboard -w tw-raw`），再 `git pull`。
3. 在 tw-raw 分支執行 `mkdir -p work && python3 tools/allring/parse.py raw/6187/fs work/fs.json`、`python3 tools/allring/rd.py`、`python3 tools/allring/build_allring.py`（產生 `work/allring_q.json`；`write_data.py` 是第一次建檔用的，排程不要整檔覆寫），把新一季（第四季時連同 `annual`）加到 `data/allring.json`；舊季度不動。
4. 更新 `waterfall`（換成新一季，含「非控制權益」一列）、`events`（下一次財報與月營收日期；公司公告前加 `est:1`）。`guidance` 保持空（公司不給數字財測）。
5. `python3 tools/validate.py allring`；通過才繼續。
6. 查事件時間軸：轉換公司債、增資、取得不動產、子公司投資（優先重大訊息）。
7. `asOf` 改成今天（台北時間），`python3 tools/build.py`，commit、push。

## 資產負債表欄位（shOut、dilSh、cash、debt、buyback、equity、pretax、tax）

- 來源：同一份季報的資產負債表與現金流量表，取「本期」欄。
- `cash`＝現金及約當現金（1100）。`equity`＝歸屬於母公司業主之權益合計（31XX）。
- `shOut`＝普通股股本（3110）÷ 面額 10 元 －「母公司暨子公司所持有之母公司庫藏股股數」；**不含**尚未換發的債券換股權利證書（3130）。
- `buyback`＝現金流量表「庫藏股票買回成本」，年初累計相減；報表沒有這一列的期間視為 0（現金流量表只列有金額的科目）。
- `pretax`／`tax`＝繼續營業單位稅前淨利／所得稅費用；第四季＝全年－前三季。
- `debt`、`dilSh`：見已知缺口。
