# 台達電 Delta Electronics（2308）資料來源與更新步驟

- 資料檔：`data/delta.json`（schema `v1`）　頁面：`/delta/`　模板：`templates/generic.frag.html`（通用模板）
- 單位：**百萬元新台幣**（`rev`、`gp`、`opInc`、`ni`、`ocf`、`capex`、`fcf`）。財報原始單位是**新台幣仟元**，除以 1,000 後保留小數 3 位；每股數字（`eps`）為元。
- 會計準則：**IFRS 合併報表**（台灣上市公司 2013 年起採用；更早是我國舊會計準則，口徑不同，本頁不收）。
- 頻率：每季。合併財務報告約在 5 月、8 月、10 月底／11 月初、隔年 2–3 月公布；月營收每月 10 日前公告。
- 排程：週二至週六 08:30（台北）每日檢查（見 docs/SCHEDULE_PROMPT.md；公布日隔天先做「快報」，再「補完」「核對」）。排程只補「上次資料之後」的新期間，舊數字不重抓、不重核；**某個月沒有新財報時，只檢查事件時間軸與公布日**；沒有實質變動就不 commit。

## 期間

1Q19（2019/1–3）–最新一季。原因：公司 IR 檔案庫（filecenter.deltaww.com）目前只取得到 2020 年起的季報 PDF，2019 年數字取自 2020 年報告的「比較欄」；公開資訊觀測站（MOPS）的 robots 規則不允許程式自動讀取，2018 年以前先不收錄（見已知缺口）。


## 來源（依可信度）

1. **台達電合併財務報告（會計師查核／核閱）**：`https://filecenter.deltaww.com/ir/download/financial_report/Q{季}{年}_chi_Consolidated Financial Report.pdf`
   - 例：`Q32026_chi_Consolidated Financial Report.pdf`。**檔名不一定一致**：`Q3 2025_chi_ Consolidated Financial Report.pdf`、`Q4 2025_chi_ Consolidated Financial Report.pdf`（年份前有空白、`_` 後有空白）。找不到時用 WebSearch 搜 `filecenter.deltaww.com financial_report Q{季}{年}`。
   - WebFetch 讀得到（PDF 轉文字），容器 curl 會被擋。讀「合併綜合損益表」與「合併現金流量表」即可，都在前 10 頁。
2. **法說會簡報（Analyst Meeting）**：`https://filecenter.deltaww.com//ir/download/calendar/{季}Q{yy}_Analyst Meeting.pdf`（例 `4Q25_Analyst Meeting.pdf`）。**第四季單季 EPS 只在這裡**（財報只有全年）。簡報數字是十億元，只拿來核對與取第四季 EPS。
3. 公開資訊觀測站 `https://mops.twse.com.tw/`：法定申報，程式讀不到，只能人工核對。
4. 可信媒體：**只用於事件時間軸**；公司未證實的一律 `unc:1`。

## 欄位定義（`quarters[]`）

| 欄位 | 財報科目與口徑 |
| --- | --- |
| `rev` | 營業收入合計（4000） |
| `gp`、`gm` | 營業毛利淨額（5950）；`gm`＝`gp`÷`rev`×100 |
| `opInc`、`om` | 營業利益（6900） |
| `ni` | 淨利歸屬於母公司業主（8610），**不是**本期淨利（含非控制權益） |
| `eps` | **基本每股盈餘**（9750）。第一到第三季取財報單季欄；第四季取法說會簡報的第四季 EPS（簡報註明以流通股數計算，數字與基本 EPS 一致）。不用稀釋 EPS，因為第四季沒有公布 |
| `ocf` | 營業活動之淨現金流入；財報只有年初累計，單季＝本期累計－上季累計 |
| `capex` | 取得不動產、廠房及設備（正數）；同樣用累計相減 |
| `fcf` | `ocf − capex` |
| `dps` | 一律 `null`：台達電一年配一次現金股利，不是每季 |

### 第四季推算
**4Q ＝ 全年（年度合併財務報告）－ 前三季單季**（營收、毛利、營業利益、淨利）；現金流＝全年－前三季累計。**EPS 不能相減**，取法說會簡報。推算結果要和簡報的十億元數字一致（例：4Q25 營收 161.6、淨利 17.3）。

### 核對（除了 validate.py）
- 每年四季基本 EPS 加總＝全年基本 EPS（2019–2025 年都相等）。
- 第四季推算值四捨五入到十億元＝法說會簡報的數字。

## 核對規則（`python3 tools/validate.py delta`）

1. 毛利率、營業利益率與金額自洽；`fcf = ocf − capex`。
2. 四季加總 ＝ 全年（營收、毛利、營業利益、淨利、營業現金流、資本支出）。
3. `waterfall` 每個小計 ＝ 前一個小計 ＋ 中間各項；第一列營收＝最新一季 `rev`。
4. 日期格式正確。

**任何一項沒過就不發佈**，回到來源修資料，不要放寬核對。

## 更新步驟（每日排程「快報」步驟；補完、核對見 docs/SCHEDULE_PROMPT.md）

1. 查有沒有新的合併財務報告：WebFetch 試 `Q{下一季}{年}_chi_Consolidated Financial Report.pdf`（含上面列的空白變體），或 WebSearch。**沒有新財報 → 跳到第 6 步。**
2. 第一到第三季：讀單季損益欄（營業收入、營業毛利淨額、營業成本、各項營業費用、營業利益、營業外、所得稅、母公司淨利、非控制權益、基本 EPS）與現金流累計欄，新增一季到 `quarters[]`。
3. 第四季：讀年度報告的全年數字算第四季；讀當季法說會簡報取第四季 EPS；新增 `annual`（`note` 寫取自哪一份報告）。
4. 更新 `waterfall`（換成新一季，含非控制權益一列）、`events`（下一次財報與月營收日期；公司公告前加 `est:1`）。`guidance` 保持空（公司不給數字財測）。
5. `python3 tools/validate.py delta`；通過才繼續。
6. 查事件時間軸：配息、併購、重大投資（優先公司重大訊息與 IR 新聞稿）。
7. `asOf` 改成今天（台北時間），`python3 tools/build.py`，commit、push。

## 已知缺口（頁面「沒能取得的欄位」會列出）

- 2018 年以前季度：IR 檔案庫現有網址格式取不到 2019 年以前的季報；MOPS 不允許程式讀取。之後若找到檔案，可往前補到 2013 年（IFRS 起點），補的時候要整段連續。
- 4Q21 EPS：4Q21 簡報 2.41 元、4Q22 簡報 2.42 元（1Q21 重編）；採 2.42。
- 3Q26 會計師核閱為保留結論（部分非重要子公司未經核閱，占總資產 6.64%）。
- 每股股利：年配，不放 `dps`。
- 事業群營收（電源及零組件、交通、自動化、基礎設施）：簡報有，尚未收錄；之後要加就放 `segments`。

## 資產負債表欄位（shOut、dilSh、cash、debt、buyback、equity、pretax、tax）
- 單位：新台幣百萬元（財報仟元÷1,000，保留 3 位小數）；股數百萬股。**範圍：1Q23～3Q26 共 15 季**；1Q19～4Q22 為 `null`（尚未讀取）。
- 來源：合併財務報告 `https://filecenter.deltaww.com/ir/download/financial_report/Q{季}{年}_chi_Consolidated Financial Report.pdf`（讀了 2024 Q1–Q4、2025 Q1–Q4、2026 Q1–Q3；2025 Q3、Q4 的檔名要用 `Q3 2025_chi_ Consolidated Financial Report.pdf` 格式，其餘用 `Q12024_chi_Consolidated Financial Report.pdf` 格式）。每份資產負債表有本期、上年底、上年同期三欄，損益表有本期與上年同期，所以 2024 報告提供 2023 年數字。法說會簡報 `3Q26_Analyst Meeting.pdf` 只用來佐證股數。
- 口徑：
  - `cash`＝現金及約當現金。`equity`＝歸屬於母公司業主之權益合計。
  - `debt`＝短期借款＋一年或一營業週期內到期長期負債＋應付公司債（非流動）＋長期借款（非流動）；**不含租賃負債**，一年內到期長期負債是否含流動租賃負債財報未拆。資產負債表沒有應付短期票券。
  - `pretax`／`tax`＝稅前淨利／所得稅費用（正數）。1Q～3Q 取單季欄；**第四季＝全年（年度報告）－前三季累計（隔季報告比較欄）**。
  - `buyback`＝0：資產負債表沒有庫藏股票科目、各期籌資活動現金流量沒有庫藏股買回項目。
  - `shOut`＝普通股股本 25,975,433 仟元 ÷ 面額 10 元＝2,597.543 百萬股（換算值；3Q26 法說會簡報註明 EPS 以在外流通股數 2,598 百萬股計算，一致）。
  - `dilSh`：全部 `null`。加權平均股數在財報附註「每股盈餘」，WebFetch 讀到的 PDF 文字在附註之前就截斷，讀不到；不用淨利÷稀釋 EPS 反推。
