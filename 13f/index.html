資料來源與口徑

  • 來源：書面（SEC 13F）。每個數字都來自 SEC EDGAR 的申報檔（primary_doc.xml 與持股表 XML），由 GitHub Actions 抓取，名稱用申報檔的 nameOfIssuer 原文。
  • 落後：13F 在季末後最多 45 天才公開，看到的是季末那天的持股，不是現在。
  • 只有多單、只有 13(f) 證券：不含空單、現金、債券（多數）與美國以外掛牌的股票；可以申請保密延後揭露，申報檔標示時會寫在卡片上。
  • 合併列：同一檔證券（同 CUSIP）常被拆成多列（例如 Berkshire 依管理單位分列），本頁加總成一檔；占比＝市值 ÷ 該季總值。
  • 本季變化：比股數（不是比市值）；上一季沒有申報、只有 13F-NT 通知或季別不連續就不顯示（待確認）。出清＝上一季有、本季沒有。
  • 修正版：整份取代（RESTATEMENT）的修正版以修正版為準；只補列的（NEW HOLDINGS）加到原始上。
  • 13F-NT：主申報人只送通知、持股由別的申報人（例如母公司）申報時，卡片會寫明；沒有可對照的持股就不補數字。
  • 本站公司對照：只有 CUSIP 在 data/13f/config.json 的對照表裡的持股才算本站公司，不用名稱猜；對照表尚未確認的公司標「待確認」。
  • 為什麼追這位：卡片上的說明是教學（Claude 的整理），不是申報檔的內容。
  • 本頁是個人研究整理，不構成投資建議。
