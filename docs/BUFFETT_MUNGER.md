# 巴菲特＋蒙格的觀念與指標（頁面文字與 prompt 都以這份為準）

網站的目的是「成長＋價值投資」。成長指標不拿掉；是把「報酬率、真實盈餘、價格」補到和成長一樣顯眼。

## 硬規則
1. **觀念一律是意譯，不是原話。** 頁面固定標「觀念（意譯，不是原話）」並帶「觀點」標籤。不要用引號包住一句話假裝是引述，不要寫年份、信件出處、數字典故。只能用下面清單裡的觀念。
2. 「巴菲特＋蒙格口吻」＝第一人稱、白話、短句的意譯，區塊標題標明「巴菲特＋蒙格口吻（意譯）」。
3. 數字全部由程式用 repo 既有欄位算（`tools/buffett.py`，建置時），算不出來寫原因，不估計、不內插。
4. 第 ① 關（能力圈）與「反過來想」只有提問：不做表單、不存檔、不要 ZL 填。

## 觀念清單（意譯）
| 代號 | 觀念 | 用在哪 |
|---|---|---|
| C1 能力圈 | 只投資自己看得懂的生意；看不懂就放進「太難」那一堆，不丟臉 | 檢查表第 1 關、分析結論「太難，跳過」 |
| C2 護城河 | 好生意有對手搶不走的優勢，表現在長期穩定的高報酬率與毛利率 | ROE、ROIC、毛利率、十年成績單 |
| C3 報酬率先於成長 | 成長只有在投入資本的報酬率高的時候才創造價值 | 營收年增、ROE、ROIC 的備註 |
| C4 業主盈餘 | 真正屬於股東的錢＝賺到的現金扣掉維持生意必須花的錢；股票酬勞是真實費用 | 自由現金流、股票酬勞、扣酬勞後現金流 |
| C5 少負債 | 好生意不需要很多負債；負債讓你在壞年份沒有退路 | 淨負債幾年還清 |
| C6 資本配置 | 管理層最重要的工作是決定賺來的錢怎麼用；回購只有在價格低於價值時才對股東有利 | 回購成績單、稀釋股數 |
| C7 一元測試 | 公司每留下一元盈餘，長期應該至少創造一元市值 | 保留盈餘測試 |
| C8 安全邊際 | 用明顯低於價值的價格買，留下犯錯的空間 | 估值上限、盈餘殖利率對公債 |
| C9 利率是地心引力 | 利率越高，所有資產的價值被拉得越低；股票要跟公債比 | 盈餘殖利率對公債、升降息頁 |
| C10 市場先生 | 股價每天報價，可以利用他，不必聽他的；價格波動不是風險，永久虧損才是 | 每日股價、估值訊號、今天該看什麼 |
| C11 反過來想 | 先想這件事怎麼失敗，然後避開 | 檢查表「它會怎麼死」、風險 |
| C12 坐著不動 | 買到好公司後，大部分時間什麼都不做；頻繁動作是報酬的敵人 | 分析結論預設「不動」 |
| C13 機會成本 | 每個投資都要跟你最好的替代選擇比；多數人定期買指數就很好 | 對指數比較、定期定額回測 |
| C14 不預測總經 | 不靠預測利率、景氣、大盤來決定買賣 | 升降息頁備註 |
| C15 循環看整輪 | 循環生意要看整個景氣循環的平均獲利，不看高峰那一年 | 十年平均獲利本益比 |
| C16 好公司合理價 | 用合理的價格買很好的公司，勝過用很便宜的價格買普通公司 | 首頁說明（成長＋價值的結合） |

## 四關加一個反向問題（個股頁「檢查表」）
```
① 我看得懂嗎（能力圈）     只有提問，沒有數字
② 護城河撐得久嗎           ROE 達標季數、EPS 成長年數、虧損年數、毛利率三年變化、十年成績單
③ 管理層會用錢嗎           回購買在偏貴／偏便宜、股數五年變化、每留 1 元盈餘創造幾元市值
④ 價格有安全邊際嗎         盈餘殖利率對公債、價格隱含的成長、對指數 1／3／5／10 年、十年平均獲利本益比
反過來想：它會怎麼死       論點卡風險＋三個通用問題
```

## 三個賣出理由（只有這三個）
A 護城河壞了（結構性，不是單季）。B 管理層變了。C 貴到離譜，而且有明顯更好的去處。
單季不如預期、股價下跌、利率變化都不是賣出理由。分析結論五選一：不動（預設）／加碼／減碼／觀察／太難，跳過。

## 指標對應（公式只有 `tools/buffett.py` 一個計算處）
| 指標 | 公式 | 觀念 |
|---|---|---|
| 盈餘殖利率對公債 | 100 ÷ 本益比（最新月底）− 十年期公債殖利率（TWD 用台灣、USD 用美國；其他幣別沒有資料，不算） | C8 C9 |
| 十年成績單 | 年度點（每隔四季一點，最多 11 點）的近四季 EPS、EPS 年增、ROE、毛利率、淨利率、FCF÷淨利、資本支出÷淨利、淨負債÷淨利、每股淨值 | C2 C3 C5 |
| 回購成績單 | 每個年度點近四季回購、那 12 個月平均本益比對近 5 年中位數（±10%）、股數五年變化、回購占市值 | C6 |
| 保留盈餘測試 | （現在市值 − 五年前市值）÷（近 20 季淨利 − 近 20 季股利） | C7 |
| 對指數 | 股價報酬對同幣別價格指數（S&P 500、臺灣加權股價指數），兩邊都不含股利 | C13 |
| 價格隱含的成長 | g ＝ ((本益比 × 1.1^10) ÷ 終點本益比)^(1/10) − 1；假設十年後 15（另算 20）倍、不計股利與回購、要求年報酬 10% | C8 |
| 十年平均獲利本益比 | 最新月底收盤價 ÷ 年度點近四季 EPS 平均（至少 5 點） | C15 |
| 類型資格（tenYearOk） | 至少 40 季、近 10 個年度點沒有虧損、近 40 季 ROE 有值 20 季以上且 80% 以上達 15% | C2 |
