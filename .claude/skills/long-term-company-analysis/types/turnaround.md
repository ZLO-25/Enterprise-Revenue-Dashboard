# 轉機／早期型（例：TSLA 現階段、RKLB、GEV*、早期 PLTR）
*歸類以網站論點卡為準。

作者對這類公司特別看（依 TSLA、PLTR 早期、SE、Intel 筆記）：
1. 用需求指標判斷是供給問題還是需求問題（交車存貨天數）。
2. 本業毛利率能否撐住降價（扣除碳權等一次性）。
3. 新業務里程碑與時程（FSD 版本、Robotaxi 城市與車隊、Optimus 產量）。
4. 現金水位與燒錢速度、調整後 EBITDA 轉正順序（SE 熊市）。
5. 砍掉無效擴張是正面訊號。
6. 第二引擎是否已能自給（TSLA 儲能）。
7. 揭露口徑改變 = 營運重心改變。
8. 計畫容錯度：「要考 120 分才及格」的計畫，一延誤就連鎖出事（Intel 四年五節點）。

作者在這類公司常犯的錯（要修正，這類最嚴重）：
- 時程一再跟著創辦人延誤 → 時程延後 6–12 個月，Musk 體系數量除以 3。
- 把管理層路線圖當進度證據 → 只認已出貨、已認列的。
- 訂單積壓當成永久需求、相信價格戰會收斂 → 寫出反方情境。
- 信念壓過估值紀律（「永遠不押注馬斯克失敗」）→ 必寫「如果我錯了，會先看到什麼」。

估值：多數時候本益比無意義；用情境（樂觀／基準／悲觀）列出各自需要的里程碑，並寫明「目前價格隱含哪個情境」。
