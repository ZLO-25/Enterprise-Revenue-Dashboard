# 選擇權型（例：RKLB、SPCX）

還沒有穩定獲利、買的是「一個可能性」的公司。巴菲特＋蒙格檢查表的第 ②③④ 關多半算不出來，這是正常的，不要硬算。

分析重點：
1. **能不能看懂**：這家公司十年後靠什麼賺錢？講不清楚就走「太難，跳過」。
2. **里程碑是否可驗證**：看營收、出貨量、發射次數、在手訂單這類可以對照財報的數字，不看願景。
3. **現金撐得住嗎**：現金、有息負債、每季燒掉多少；需要大幅增資才能走下去，要寫出稀釋多少。
4. **稀釋**：股數年增（稀釋股數年增）寫出原因與對每股的拖累。
5. **部位大小**：觀點寫成「金額要小到全部虧掉也不影響生活」（意譯），不要用估值倍數替它辯護。

論點卡的「論點破了」：連續兩年沒有可驗證的營收或數量里程碑，或需要大幅增資才能繼續。

結論預設「不動」；沒有可驗證里程碑時，是「觀察」或「太難，跳過」，不是「加碼」。
