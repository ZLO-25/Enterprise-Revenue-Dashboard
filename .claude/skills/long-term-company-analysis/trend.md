# 趨勢分析（世界科技趨勢報告）

## 流程
1. 用一個具體事件開場（發表會、財報、政策、總經數據）。
2. 說清楚爭議：是炒作還是大趨勢？誰會贏？
3. 先下定義、收窄範圍（定義寬到等於整個網路就沒有討論價值）。
4. 拆成幾部分逐項推理，每項一個小結論，配一個生活化例子。
5. 真趨勢五問：
   - 定義能不能收窄成具體體驗或能力？
   - 使用頻率與時間成本：極致便利 → 主流；極致體驗 → 小眾。
   - 巨頭怎麼下注、下注是否合理（但「說得通」≠「會成功」）。
   - 生產力是否立刻可見？
   - 終端有沒有人付錢、價值流向誰？（真趨勢也可能是壞投資）
6. 落到公司：先找賣鏟子的 → 意外受益者與受害者 → 按業務分部排敏感度 → 誰的擴張邊際成本最低。只寫網站追蹤的公司。
7. 結論與預測：方向＋時程＋信心，三段分開寫。

## 常用思考工具
護城河拆解｜歷史類比（平台轉移）｜市場分段｜入口與議價權｜通用 vs 專用｜降門檻帶來網路效應｜供需與內卷（紅利被競爭壓成降價）｜合成謬誤｜景氣敏感度｜Scaling law 與先驗資訊遞減｜充分 vs 必要條件｜價值捕捉（增量 vs 截流）｜產業激勵錯置｜情境二分法。

## 第二批補充的工具（依 2023–2026 文章）
- **使用阻力用動作數比較**：完成同一件事要幾個步驟，步驟少的勝出（眼鏡、手機、AI 助理）。
- **商業模式能否轉嫁 AI 成本**：訂閱可以加價，廣告總量不會因 AI 變多 → 誰能把成本轉給客戶。作者 2023 年就用這把尺。
- **平台 vs 周邊、聚合者 vs 重資本平台**：決定護城河能撐多久。
- **談判籌碼與讓步空間**：大型合作、授權、監管和解先問雙方各自能退多少。
- **發表會 ≠ 上線 ≠ 被使用**：三步分開記，只有第三步算證據。
- **同主題換主角前先對帳前一位**：去年捧的產品賣得如何，再談今年的新主角。
- **客座文章分開記帳**：不算進作者命中率；立場偏粉絲的要標出。

| AI 基礎設施量級 | 29%（12 條；錯的 8 條都偏悲觀，沒有一條高估） | 作者式數字當下限 |

| 新產品帶動營收 | 11%（9 條） | 上市後兩季內不預設營收貢獻 |
| 競爭格局（誰搶走誰） | 31%（8 條） | 標「低信心」，看新增容量與積壓訂單 |
| Tesla／Optimus／Robotaxi 數量時程 | 33%（20 條）；新產品數量 5 條全錯 | 見 types/turnaround.md；時程延後約 1 年 |
| 監管方向／落地速度 | 約 60% | 方向 0.8 倍、速度打 5 折 |
| 新硬體品類熱潮 | 偏樂觀 | 持續性打 6 折 |
| 景氣下行途中（2022 年發文） | 「下一季到一年會變差」9 條命中 94%；但一年內的數字 13 條命中 35%，都偏樂觀 | 方向照收；數字取作者區間下緣以下 |
| 谷底看衰傳統事業（2023 年發文） | 50%（9 條）；錯在把低迷寫成常態、上限壓太低 | 短期方向照收；「常態」「長期」說法不採用 |
| 不熟領域、資產價格 | 約 25% | 標「低信心」 |
| 「機率低於 1%」「全面放棄」「不需要懷疑」等絕對化說法 | 無推導 | 不採用，改寫成條件句 |
| 作者用 Musk 目標當參數的自建模型 | 偏樂觀 | 一樣打折 |

## 定期世界趨勢報告格式
```
# 世界科技趨勢 <期間>
## 本期 3 件大事（事件｜為什麼重要｜影響哪幾家追蹤公司 ↑↓）
## 主題追蹤（AI 算力供需／AI 應用變現／半導體週期／能源與電力／監管與地緣）
   每個主題：上期判斷 → 本期新證據 → 判斷維持或修正
## 預測帳本（過去預測的對帳：✓／✗／未到期）
## 對追蹤公司的含意（只列有變化的）
```
每期都要回頭對帳上期預測，這是作者做得最差、也最能提升可靠度的一步。
